# Solar Intelligence Platform

## Overview
Solar Intelligence Platform is an AI-powered SaaS application designed to help residential solar system owners maximize the financial value of their systems.

The platform provides:
- Solar production forecasting
- Predictive maintenance insights (dust, heat, weather risks)
- Energy usage optimization recommendations
- Financial impact estimation
- AI-generated daily and weekly insights

## Target Users
- Residential solar system owners
- Future: solar installers and small commercial sites

## Core Value
The system transforms raw solar and weather data into:
- Clear actions
- Financial insights
- Optimization opportunities

## V1 Scope
- Forecast-based analysis (no hardware integration)
- Deterministic calculation engine
- AI explanation layer (non-critical)

## Out of Scope (V1)
- Live inverter integration
- Smart home control
- Battery optimization
- EV charger control
- Advanced anomaly detection

## Tech Stack (High Level)
- Frontend: Next.js + React + TypeScript + Tailwind
- Backend: Node.js (NestJS)
- Engine: Python (FastAPI)
- Database: PostgreSQL
- AI: OpenAI (insight generation only)

## Product Type
AI-powered Solar Optimization SaaS Platform
