# Task Template

Use this template for every implementation task.

## Task ID
- Phase-X.Y

## Status
- planned | active | needs-audit | blocked | done

## Goal
- One clear outcome in one sentence.

## Scope
Included:
- Specific modules/files allowed to change.

Excluded:
- Explicitly list what must not be changed.

## Inputs
- Relevant source-of-truth docs
- Relevant existing files/modules
- Contracts/schemas involved

## Deliverables
- Files to create/update
- Expected behavior/output after implementation

## Constraints
- Keep architecture unchanged unless approved.
- Keep implementation deterministic where required.
- Do not expand to future-phase logic.
- Keep touched services runnable at task end.

## Validation Plan
- Commands/checks to run
- Expected pass criteria

## Required Report Format
1. Files created/modified
2. Logic added/changed
3. Validations executed and outcomes
4. Remaining TODOs/blockers

## Done When
- Exact closure criteria for this task.
- Explicit evidence required to mark task done.
