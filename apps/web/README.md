# apps/web

Web application for Solar Intelligence Platform.

## Design Baseline (Phase 1.7)

- Tokenized visual system in `src/app/globals.css`
- `shadcn`-style component setup (`components.json`)
- Core UI primitive: `Button` in `src/components/ui/button.tsx`
- Layout shell: `src/components/layout/app-shell.tsx`
- Motion baseline using `framer-motion`

## Run

```bash
npm run dev
```
